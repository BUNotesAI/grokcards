- App.tsx 改用 typed `commands.greet()` 替代 raw `invoke()`

### 关键决策
| 决策 | 原因 |
|------|------|
| 不用 hooks，用 CLAUDE.md 流程规则 | 项目初期轻量，hooks 增加复杂度 |

| bindings.ts 加入 .gitignore | 生成文件不提交，避免 merge 冲突 |
| 用 test 生成 bindings 而非 app 启动 | CI/CLI 环境无 GUI，test 更通用 |

## Session 5 — Phase 2: Tauri commands + specta 绑定

### 关键数据
| 指标 | 值 |
|------|-----|
| 新增测试 | 0（接线层无新逻辑） |
| 回归 | 0（122 workspace tests 全过） |
| 新增文件 | state.rs, commands.rs |
| bindings.ts | 603 lines，含 40 keysight commands |
| commits | 5（`ff79875`→`7151ad7`） |

### 决策
| 决策 | 原因 |
|------|------|
| KeysightState 独立 DB | keysight 是产品，todo 是 demo，不共享 |
| 跳过 task/question 模块 | by_status 返回 serde_json::Value，specta 不支持 |
| 移除 skip_serializing_if | specta unified mode 不支持条件序列化 |
| 不新增 command 层测试 | 薄壳 ≤4 行，验证靠 bindings 生成 + TS 编译 |

### 经验
- 验证报告要精确：测试数量未变时说"0 回归"而非重复总数
- subagent 批量执行机械性 task（visibility 替换 + commands.rs copy）效率高
- specta 的 serde 兼容性有坑（skip_serializing_if 不支持），需注意
